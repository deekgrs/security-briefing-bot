## [High] Zeabur shutting down after second security breach in two months
*Breach · BleepingComputer* - [Read more](https://www.bleepingcomputer.com/news/security/zeabur-shutting-down-after-second-security-breach-in-two-months/)

Cloud development platform Zeabur is shutting down after suffering its second security breach in two months. Attackers stole millions of configuration records and account information using leaked internal passwords.

**What to do (everyone):** If you had an account on Zeabur, assume your information and any secret configuration keys (environment variables) you stored there were exposed. You should immediately change any passwords and API keys that you used on the platform.

**What to do (IT teams):** Review any systems that integrated with Zeabur, rotate all API keys and credentials that were stored on the platform, and prepare to migrate services away as the company shuts down.
